## Features

*   **Application Dashboard:** Track your job search pipeline through customizable stages (Applied, Interviewing, Offer, Rejected) in one centralized view.
*   **AI Evaluator:** Upload your CV and paste a Job Description to get an instant match score, role-specific gap analysis, and actionable rewrite suggestions.
*   **Interview Forecaster:** Automatically generate high-probability technical and behavioral interview questions tailored to the specific role and company.
*   **Funnel Visualizations:** Analyze your conversion rates and identify drop-off points using interactive Sankey diagrams and analytics charts.
*   **Cloud Synchronization:** Keep your career data seamlessly synced across all your devices using Firebase Firestore.
*   **Secure Authentication:** Protect your personal pipeline data with robust Firebase Authentication.
*   **Data Export:** Export your complete application history as a CSV file for personal backup or external analysis.

## Getting Started

### Prerequisites

- Node.js
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your `.env` file with Firebase credentials.
4. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used
