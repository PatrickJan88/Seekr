## Features

- **Dashboard**: Track your job applications through various stages (Applied, Interviewing, Offer, Rejected, etc.).
- **Visualizations**: View your job search funnel through Sankey diagrams and analytics charts.
- **Data Export**: Export your application data as a CSV file.
- **Authentication**: Secure your data with Firebase Authentication.
- **Cloud Synchronization**: Sync your application data across devices with Firebase Firestore.

## Getting Started

### Prerequisites

- Node.js
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your `.env` file with Firebase credentials.
4. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used
